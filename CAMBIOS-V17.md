# DECOGLASS V17 — pedidos listos visibles de un vistazo

- La tarjeta principal de un pedido con un solo espejo listo ahora muestra un marco verde completo.
- Si todos los espejos de un pedido múltiple están listos, toda la tarjeta principal muestra el mismo marco verde.
- Si solamente una parte del pedido múltiple está lista, la tarjeta muestra una marca verde lateral y el contador `1/2 listos`, sin dar a entender que todo el pedido terminó.
- El indicador aparece con la tarjeta cerrada y funciona tanto en tema oscuro como claro.
- Se mantiene el marco verde que ya existía dentro de cada subtarjeta de espejo.
- No requiere cambios en Supabase.
